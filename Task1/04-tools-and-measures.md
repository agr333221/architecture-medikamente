# Задание 1.3. Инструменты, способы и меры обеспечения конфиденциальности

Стек выбран с учетом компетенций IT-отдела (Java, PostgreSQL, ClickHouse, Elastic, Kubernetes,
VictoriaMetrics), требования локализации ПДн в РФ (152-ФЗ ст. 18 ч. 5) и возможности
использования сертифицированных ФСТЭК средств там, где это требуется для ИСПДн.

| Область | Мера | Инструмент | Потоки (DFD) |

## 2. Организационные меры

1. Назначить ответственного за организацию обработки ПДн (DPO) и Data Steward по доменам.
2. Утвердить политику обработки ПДн, модель угроз, определить уровень защищенности ИСПДн
   (ПП 1119; для данных о здоровье - специальная категория), уведомить Роскомнадзор.
3. Заключить договоры-поручения с лабораторией, провайдером уведомлений, облачным / хостинг-
   провайдером (если будет использоваться), эквайером.
4. Внедрить формы согласий по целям обработки (лечение, запись, маркетинг, аналитика).
5. Регламенты: сроки хранения, уничтожение, реагирование на инциденты (уведомление РКН в 24/72 ч),
   выдача и отзыв доступов при найме / увольнении.
6. Обучение сотрудников при приеме на работу и ежегодно.

## 3. Соответствие мер потокам данных

| Поток | Ключевые меры |
| --- | --- |
| DFD-01 Регистрация | Минимальная анкета, согласия по целям, шифрование ID/PHI, документы в S3 без ПДн в именах |
| DFD-02 Запись | ABAC (свои записи / свое расписание / свой филиал), токены в событиях, уведомления без медсведений |
| DFD-03 Медкарта | ABAC "лечащий врач", break-glass, УКЭП, шифрование полей, DLP |
| DFD-04 Лаборатория | Псевдонимизированный контракт API, mTLS + OAuth2, защита от BOLA, договор-поручение |
| DFD-05 Оплата | Платежная страница эквайера (PAN не хранится), обобщенные наименования услуг, единый источник платежей |
| DFD-06 Бухгалтерия | 1С клиент-сервер, VDI, роли, ДиректБанк / ЭДО с УКЭП |
| DFD-07 Склад | Списание по visit_id, DLP-правило на комментарии |
| DFD-08 Аналитика | Классификация на входе, слои raw/curated/marts, псевдонимизация и обезличивание, lineage |

Как меры отображены на каждом этапе потоков - см. страницы To-Be в файлах `diagrams/DFD-0x-*.drawio`
(зеленые стрелки и метки [Мn]).
