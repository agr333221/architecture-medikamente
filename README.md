# architecture-medikamente

Проектная работа 10 спринта: защита конфиденциальных данных и миграция информационной системы
медицинской компании "Медикаменте" (Privacy by Design, Data Minimization, Data Lineage).

| Задание | Директория | Результат |
| --- | --- | --- |
| 1. Анализ безопасности системы | [Task1](Task1/README.md) | DFD по 8 процессам (As-Is и To-Be, draw.io), список проблем, список данных для защиты, механизм тегирования, инструменты и меры |
| 2. Проектирование решения | [Task2](Task2/README.md) | C4 Context целевого состояния (MVP -> Target) с блоками Privacy by Design и аналитическим слоем; C4 Container; домены данных и RBAC/ABAC |
| 3. Data Encryption at Rest and In Transit | [Task3](Task3/README.md) | Классификация данных, обоснование защиты, инструменты, автоматизированный контроль, реестр средств защиты |
| 4. Оценка узких мест при миграции | [Task4](Task4/README.md) | Диаграмма Исикавы (draw.io) и отчет с приоритизированными рекомендациями |
| 5. Cutover-план | [Task5](Task5/README.md) | Обоснование Parallel run, cutover-план (таблица + блок-схема draw.io), риски, роли, план отката |
| 6. Классификация данных | [Task6](Task6/README.md) | C2 движка классификации перед загрузкой в хранилище (draw.io), слои хранилища, метрики, масштабирование |

Все диаграммы сделаны в draw.io (`.drawio`), рядом лежат экспортированные `.png`.
